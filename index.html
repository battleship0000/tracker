Edit timetable

Change name, start, and end for any block. End earlier than start means it runs past midnight. Saved timetable is used on Today, Month, and reminders.

Install this as an app

Add it to your phone home screen. Tracking works offline. Checkboxes stay on that phone.

  1. Android (Chrome): tap the menu → Install app / Add to Home screen, or use the Install app button above.
  2. iPhone (Safari): Share → Add to Home Screen.

Phone reminders when the phone is locked

Install does not replace calendar alerts. Import this file once so your phone notifies you 15 minutes before each block even if the app is closed.

Download calendar file

  1. Android: open routine.ics → Google Calendar → import. Allow Calendar notifications.
  2. iPhone: open the file → Add All.
